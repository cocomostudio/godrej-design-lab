
# about
This houses code for the Godrej Design Lab website, specifically:
- Strapi CMS app
- Frontend app

# quick start

```
$ git clone git@github.com:cocomostudio/godrej-design-lab.git
$ pnpm fetch -r
$ pnpm install -r --offline --frozen-lockfile
```

CMS 

```
$ pnpm -F cms run build
$ pnpm -F cms run start
```

Frontend

```
$ pnpm -F few run build
$ pnpm -F few run start
```
